# Salomon Owona - Personal Website

Multi-language personal website for Salomon Firmin Owona.

## Languages
- 🇩🇪 Deutsch (German) - index.html
- 🇬🇧 English - en.html
- 🇫🇷 Français (French) - fr.html
- 🇸🇿 Kiswahili (Swahili) - sw.html

## Features
- Responsive design with Tailwind CSS
- Hamburger menu navigation
- Archive.org radio player (13 historical tracks)
- Dark theme with gold accents
- Language switcher
- Mobile-optimized

## Deployment
Deployed on Vercel at https://salomonowona.com

## Development
All files are static HTML with inline Tailwind CSS and JavaScript.
No build process required.

## Files
- `index.html` - German version (default)
- `en.html` - English version
- `fr.html` - French version
- `sw.html` - Swahili version
- `Salomon.png` - Hero background image
- `vercel.json` - URL rewrite configuration
